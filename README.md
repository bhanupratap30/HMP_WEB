# 🏨 HMP_WEB - Hotel Management Web Project

## 📌 Project Description

HMP_WEB is a simple hotel management web application that allows users to book rooms, manage accounts, and search for available hotel services. This project demonstrates the use of frontend technologies along with C++ and DSA concepts for backend logic.

---

## 🚀 Features

* User Signup and Login
* Room Booking System
* Room Search and Availability Check
* Customer Record Management
* Location-Based Room Search

---

## 🛠 Technologies Used

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* C++
* Data Structures and Algorithms (DSA)

---

## 📂 Project Structure

```
HMP_WEB
│
├── HTML Files (Frontend Pages)
├── CSS Files (Styling)
├── JavaScript Files (User Interaction)
├── C++ Files (Backend Logic)
├── DSA Implementation (Data Handling)
```

---

## ▶️ How to Run the Project

1. Download or clone the repository
2. Open HTML files in a browser to view frontend
3. Compile C++ files using any C++ compiler
4. Run backend logic for booking and management

---

## 📚 Learning Objective

This project helps in understanding:

* Web development basics
* Integration of frontend and backend
* Use of Data Structures in real-world applications
